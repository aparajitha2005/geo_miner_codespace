# GeoMiner – Predictive Modelling for Mineral-Rich Zones

## About the Project

**GeoMiner** is a final-year project focused on the predictive identification of mineral-rich zones using geochemical data and geological imagery.

The project combines multiple data modalities, including:

* Numeric geochemical data
* Geochemical imagery
* Structural and lineament imagery

The project involves data preprocessing, mineralisation scoring, machine learning and deep learning-based modelling, multi-modal data fusion, and explainable AI.

---

## Repository Purpose

This repository contains the code developed and used throughout the GeoMiner project.

The code will be organised into separate sections based on the different stages of the project pipeline, including:

1. Data preprocessing
2. Mineralisation scoring
3. Machine learning models
4. Deep learning models
5. U-Net-based image processing/segmentation
6. Multi-modal modelling
7. Explainable AI
8. Model inference and API
